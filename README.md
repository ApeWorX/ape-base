# Quick Start

Ecosystem Plugin for [Base](https://base.org/) support in Ape.

## Dependencies

- [Python 3](https://www.python.org/downloads) version 3.10 or greater.

## Installation

### via `pip`

You can install the latest release via [`pip`](https://pypi.org/project/pip/):

```bash
pip install ape-base
```

### via source

You can clone the repository and install for development:

```bash
git clone https://github.com/ApeWorX/ape-base.git
cd ape-base
uv sync --group dev
uv run prek install
```

## Quick Usage

Installing this plugin adds support for the Base ecosystem:

```
ape console --network base:sepolia
```
